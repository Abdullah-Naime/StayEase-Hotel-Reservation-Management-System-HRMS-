# StayEase – Hotel Reservation Management System (HRMS) 🏨

A modular, Python command-line Hotel Reservation Management System (HRMS) designed to streamline room bookings, guest check-ins, housekeeping, billing, and performance analytics across multiple administrative roles.

## Features ✨

* **Role-Based Portals:** Dedicated access and functionality for Managers, Receptionists, Accountants, Housekeeping staff, and Guests.
* **Reservation System:** Book, view, modify, or cancel room reservations with automated room assignments.
* **Guest & Billing Management:** Register guest profiles, process check-ins/check-outs, calculate late check-out fees, and generate itemized receipts.
* **Housekeeping & Maintenance:** Track daily room cleaning schedules, update maintenance statuses, and log room issues.
* **Financial & Analytics Reports:** Generate income summaries, track outstanding payment lists, and view daily/monthly hotel performance reports.
* **Local File Persistence:** Reads and writes all system records directly using local text files without external database dependencies.

## Requirements 📋

* Python 3.x
* Any standard terminal environment (PowerShell, Command Prompt, Linux, or WSL)
